Implementation summary

  • Migration 017: packaging table (parallel to ingredients with currency, freight, fx_rate fields), product_packaging join, plus nullable packaging_id on stock_movements + inventory_balances, plus app_settings.fx_rates JSON for the currency table.
  • Loaded cost computed in lib/packaging-cost.ts as: price × fx_rate + freight_per_unit. Same helper is used by the form, list, PO line pre-fill, and product cost rollups.
  • New pages: /packaging (list / new / edit) and /packaging/demand.
  • PO line gains a packaging type (4th option). Pre-fills supplier code / pack size / loaded NZD price.
  • Receipt flow: when a packaging line is received, write to stock_movements with packaging_id; the existing trigger updates inventory_balances at Main Warehouse.
  • Sidebar: new "Packaging" + "Packaging demand" entries under Planning.
