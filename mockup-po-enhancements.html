Implementation summary

  • Migration 016 adds: ingredients.supplier_sku_code, supplier_pack_size, supplier_pack_unit; new delivery_addresses table; purchase_orders.delivery_address_id + delivery_notes; ensures a "Main Warehouse" location row.
  • PO line editor pre-fills supplier_sku_code, pack_size, unit_cost on ingredient pick. Soft warnings on pack-size mismatch and price drift, each with a one-click "save updated value to ingredient".
  • New page /delivery-addresses for CRUD. Sidebar entry under Admin (alongside Settings / Users).
  • New page /inwards-pending in the Procurement section. Same data as /purchase-orders?status=submitted,partial with overdue + this-week tiles.
  • Receipt flow updated: per-line "Invoice price" column (currently called Unit price) with discrepancy alert vs PO price, qty alert vs ordered. On confirm, write a row to stock_movements (movement_type = 'receipt') and increment inventory_balances at the Main Warehouse location.
  • Multi-location: schema already supports it (locations table). For v1 we only use Main Warehouse; adding more locations + a per-PO destination dropdown is a small follow-up when you're ready.
