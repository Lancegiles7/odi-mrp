PO PDF should show batch / lot numbers when receipting

Submitted by Atma Okan · 2 hours ago
Description
When we receipt a PO, we capture batch numbers (from migration 016 onwards). However, when we reprint the PO PDF after receipt, the batch numbers don't show up next to the receipted line items. This would be really useful for the QC audit trail — when we have to demonstrate which batch came in against which order, right now we have to cross-reference two separate reports. Suggest adding a small "Batch" column to the table on the PDF, filled in only when the line has been receipted.
