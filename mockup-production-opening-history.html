3 · What this would change behind the scenes

  • New table product_opening_stock_history (append-only — mirrors the existing ingredient_price_history shape). Columns: id, product_id, previous_value, new_value, note, changed_by, changed_at.
  • updateOpeningStockOverride server action now: (a) reads the existing value, (b) writes the new value to products.opening_stock_override, (c) inserts a history row capturing previous + new + note + user — all in one transaction.
  • Production row UI: replaces the raw input with the input + a small clock-style icon that opens the popover above.
  • Each monthly Bal cell gains a small sub-label "X% of fcst" (green / amber / red).
  • Read-only roles still see the icon (showing history is fine) but can't save — same as the rest of the page.
