Demand — NZ / AUS split

Proposal: country subtotals + a grand total, with a one-click filter to see all / NZ-only / AUS-only.

What changes
  • • Channels go from 5 → 6: add pipefill_au alongside the new pipefill_nz
  • • Every product table groups rows under "NZ" and "AUS" headings with subtotal rows
  • • Grand Total row at the bottom (NZ Total + AUS Total)
  • • Filter pills at the page top: All · NZ · AUS — re-renders the tables to show only that country's block
  • • Tiles + accordion totals respond to the filter (when NZ is selected, the totals are NZ-only)
Migration (one SQL run)
  • • Rename existing pipefill rows → pipefill_nz (one UPDATE)
  • • Add pipefill_au to the allowed channel list (CHECK constraint update)
  • • All existing pipefill values are treated as NZ, per your spec
  • • No data loss — pure relabel + add
  • • Where pipefill_au gets typed in: same place as the others — the new AUS row on every product table is editable just like the rest
