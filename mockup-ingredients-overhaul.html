Ingredients overhaul — proposal

Expanded filters, three new columns, At-risk status, BOM list on the detail page, and a Documents section per ingredient (COA, spec sheets, etc).

List page changes
  • • Product filter — All / Active products only / by product group (Pouches, Snacks, etc.)
  • • Supplier in search — the existing SKU/name search also matches supplier name
  • • Status gains "At risk" — Confirmed (green) · At risk (amber) · Pending (gray) · Inactive (faded)
  • • Three new columns: Origin · Certification · Docs (badge with count)
  • • Certification chip colours: GFSI · HACCP · blank when none on record
Detail page changes
  • • "Used in X BOMs" becomes a full list of products (each clickable through to the product)
  • • New Documents section — drag-and-drop / pick-file upload
  • • Per-doc tagging: COA · Spec sheet · Allergen statement · Nutritional info · Certification certificate · Pricing / quote · Other
  • • Each doc shows: filename, type, size, uploaded by + when. Click to download. Trash icon to remove.
  • • Files stored in Supabase Storage (new bucket, secured per RLS)

What we'd build
  1. Migration 033 · Add 3 columns to ingredients: origin, certification (CHECK: gfsi/haccp/null), add at_risk to the existing status CHECK constraint.
  2. Migration 034 · Create ingredient_documents table (id, ingredient_id, file_path, file_name, doc_type, size_bytes, notes, uploaded_by, uploaded_at). Create Supabase Storage bucket ingredient-docs with RLS that only authenticated users can read/write.
  3. List page · Add product-filter dropdown (URL ?group=snacks_4bs), extend the search to match supplier name (LEFT JOIN suppliers, OR on supplier.name), add Origin / Cert / Docs columns.
  4. Edit form · Add Origin (text), Certification (dropdown: GFSI / HACCP / None), expand Status dropdown to include "At risk".
  5. Detail page · Replace "Used in X BOMs" count with full product list (clickable). Add Documents section with upload button + table of files + delete.
  6. Upload action · Server action that streams file → Storage bucket, inserts row in ingredient_documents, returns success/error.

~2 hours of work end-to-end. Storage bucket setup adds a small one-time step in Supabase dashboard (or via SQL). I'll guide you through it.

A few decisions before I build
  • • Certification options: I've gone with GFSI / HACCP / None. Want to add more (Organic-NZ, USDA-Organic, BRC, ISO 22000, Kosher, Halal)? Tell me which.
  • • Origin field: free-text country (simplest), or a dropdown of common countries? I'd go free-text for v1 — easier when sourcing changes.
  • • Document types: 7 listed (COA, Spec sheet, Allergen, Nutrition, Certification, Pricing, Other). Add any? Remove any?
  • • Document expiry tracking: should COAs / certificates have an expiry date so they flag red when expired? Quick add, useful for compliance. I'd say yes.
  • • Storage retention: who can delete? Admin only, or anyone with edit access on ingredients? Default: admin only.
