3 · Original Order section — packaging / ingredients / products

Same UI block reused on all three edit forms. Captures the launch PO + lets you set today's SOH; the system auto-creates a single bulk consumption movement so Stock Movements stays the source of truth.

On save: a single stock movement entry will be created — type opening_adjustment, qty −2,600, dated 2026-05-09, with a reference back to this item. You can find it in Stock Movements.

If you re-edit current SOH later, the existing opening_adjustment is updated in place (not duplicated). Future PO receipts and BOM consumption write their own movements as normal.
