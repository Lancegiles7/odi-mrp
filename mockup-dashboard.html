Behaviour notes

  • FY toggle at the top switches all sections between FY27 / FY28 / FY29 / 3-Yr.
  • Region toggle (Combined / NZ / AU) re-filters every table and tile.
  • Re-upload XLSX button replaces the snapshot. The dashboard always shows the most recent upload (with date/user).
  • Live MRP snapshot reads operational data straight from the MRP — no upload needed; updates whenever production/POs/demand change.
  • Variance later: when actuals come in, each row gets Budget · Actual · Variance columns. Out of scope for v1 (no actuals source yet).

Implementation (for reference)

  • New migration: budget_snapshots table — one row per upload (id, source_filename, uploaded_at, uploaded_by) + child budget_line_items (snapshot_id, section, line_item, year_month, region, value).
  • New page /dashboard/budget reading the latest snapshot. Reuses existing demand/production/PO queries for the MRP snapshot section.
  • New /dashboard/budget/import XLSX upload page — same pattern as demand import. Parses "Copy of Total Business P&L", "Copy of NZ/AUS D2C", "Copy of NZ/AUS Retail" tabs into the structured table.
